# Blueprint

## Overview
This is a Next.js application initialized with `create-next-app`. It currently includes a basic landing page and a testing setup using Jest and React Testing Library.

## Project Structure & Features
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Testing**: Jest, React Testing Library
    - `jest.config.ts`: Configuration for Jest.
    - `jest.setup.ts`: Setup file including `@testing-library/jest-dom`.
    - `src/app/__tests__/page.test.tsx`: Test for the main page.
